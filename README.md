## Selected projects

- [**durable-webhooks**](https://github.com/lavreniukmisha/durable-webhooks) — Python / SQLite. Persistent outbox, signed payloads, retries, and dead-letter replay. Lease tokens keep stale workers from acknowledging a job. [Delivery notes](https://github.com/lavreniukmisha/durable-webhooks#delivery-behaviour).  
  [![durable-webhooks tests](https://github.com/lavreniukmisha/durable-webhooks/actions/workflows/tests.yml/badge.svg?branch=main)](https://github.com/lavreniukmisha/durable-webhooks/actions/workflows/tests.yml)
- [**callback-gateway**](https://github.com/lavreniukmisha/callback-gateway) — NestJS / PostgreSQL. PSP/GSP callbacks with tenant-scoped idempotency and tests for concurrent duplicates. [Decisions and tradeoffs](https://github.com/lavreniukmisha/callback-gateway/blob/main/DECISIONS.md).
- [**vue-image-editor**](https://github.com/lavreniukmisha/vue-image-editor) — Vue 3 / Canvas. Non-destructive editing, undo/redo, cropping, and full-resolution export. Image transforms live in [`src/lib/`](https://github.com/lavreniukmisha/vue-image-editor/tree/main/src/lib).
- [**fastapi-rbac-ghost-infra**](https://github.com/lavreniukmisha/fastapi-rbac-ghost-infra) — FastAPI / React take-home. Role-based permissions and Ghost deployment scripts for Hetzner and Cloudflare Tunnel. Based on the Full Stack FastAPI Template.
