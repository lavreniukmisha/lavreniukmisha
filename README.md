# Misha

TypeScript and Python. Mostly web apps, backend APIs, and automation.

## Repos worth opening

- [**callback-gateway**](https://github.com/lavreniukmisha/callback-gateway): NestJS + PostgreSQL. Incoming PSP/GSP webhooks, tenant-scoped idempotency, and tests for concurrent duplicate callbacks. Implementation choices are in [DECISIONS.md](https://github.com/lavreniukmisha/callback-gateway/blob/main/DECISIONS.md).
- [**vue-image-editor**](https://github.com/lavreniukmisha/vue-image-editor): Vue 3 + Canvas. Edits are stored as operations, so the original image stays untouched. Undo/redo, cropping, and full-resolution export. The image math lives in `src/lib/`.
- [**fastapi-rbac-ghost-infra**](https://github.com/lavreniukmisha/fastapi-rbac-ghost-infra): A take-home project: `admin` / `manager` / `member` permissions on FastAPI + React, plus Ghost deployment scripts for Hetzner and Cloudflare Tunnel. Built on the Full Stack FastAPI Template.
